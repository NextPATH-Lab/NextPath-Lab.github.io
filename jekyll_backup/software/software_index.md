## PyGaulics (Python, Cross-platform)
<p style = "text-align: justify">
PyGaulics was developed as a supplement for the Asterics suite, an auxiliary for the software named after the Gauls, 
and evolved into a stand-alone image analytics/spatial analysis powered by PyTorch, PyTorch Geometric and other 
scientific imaging packages.
</p>
